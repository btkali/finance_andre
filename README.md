# Dashboard di trading

Sito generato automaticamente da [mercati](https://github.com/).
La pagina si aggiorna da sola leggendo `dati.json` dal ramo `dati`,
che il motore ricarica ogni 60 secondi mentre e' in funzione.

- **Dashboard**: https://btkali.github.io/finance_andre/
- **Rassegna mercati**: https://btkali.github.io/finance_andre/news.html

Se i numeri sono fermi, il motore non e' in esecuzione: la pagina resta
online comunque e lo dichiara in alto a destra.
